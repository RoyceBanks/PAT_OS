# Contributing

Thank you for contributing to PAT OS.

## Code Style

- Follow PEP8
- Use type hints
- Add comments where appropriate
- Keep functions small and focused

## Commit Messages

Good examples:

Added Voice Engine

Fixed Router

Improved Memory

Added Weather Skill

## Branches

main

Stable releases

develop

Current development

feature/*

Individual features

## Pull Requests

Every pull request should:

- Compile successfully
- Pass testing
- Include documentation
- Follow project structure

## Goals

PAT OS should always be:

- Modular
- Expandable
- Reliable
- Open Source
- Privacy Focused
