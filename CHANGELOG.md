## [0.1.0] - 2026-08-06

### 🎉 Initial Alpha Release

This is the first working version of PAT OS.

### Added

#### AI
- Local AI integration using Ollama
- Custom PAT model
- Conversation support

#### Core
- Main application structure
- Modular project architecture
- Configuration system
- Intent Router

#### Memory
- SQLite database
- Long-term memory manager
- Save memories
- Recall memories
- Update memories
- Delete memories

#### Task Engine
- Task creation
- Task queue
- Task execution
- Task history
- Task cancellation

#### Automation
- Safe application launcher
- Configurable application aliases
- Windows application support

#### Development
- Virtual environment support
- Git repository
- Project documentation
- Requirements file
